# Roles

For thorough mode. Pick a fitting fixture, or none.

- **Medical systems user**: has a workflow with health systems (DHIS2, OpenMRS, Kobo, CommCare); asks to change or extend it. Fixture: `kobo-nutrition-dhis2`.
- **Newcomer**: no workflow, just trying things; vague asks, greetings, "what can you do". Fixture: none.
- **Debugger**: a run failed; shares logs and asks why. Fixture: `commcare-dhis2-broken-log`.
- **Reviewer**: asks if their workflow looks ok. Fixture: `shopify-netsuite-long`.
- **Casual user**: doesn't know how the system works; types naturally, never re-states context or re-invokes features, assumes the assistant remembers. Fixture: any.
