---
name: diagnose
description: Diagnose a failed workflow run from its logs, dataclips and workflow YAML
---

Diagnose why the run the user is asking about failed. Do not fix anything
unless they ask.

1. Read the run logs and dataclips attached to this turn. If none are attached,
   say what you need and stop.
2. Find the first real failure, not the errors that followed from it.
3. Report the failing step, the cause, and the evidence you read it from.
4. Offer a fix as a next step, and wait to be asked.
